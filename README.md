# 应急调度合成数据演练台

面向应急调度培训团队的**本地**合成数据生成与质量验证工具：从去标识化历史事件中生成可重复的练习数据，保留报警、派车、到场、结案之间的有效关系，不把原始个案复制到培训环境。

- 技术栈：React 18 + TypeScript + Vite；IndexedDB（Dexie）本地持久化；WebWorker 执行生成与核验
- 纯前端本地应用，**不调用任何外部服务**；无后端，故不提供 Swagger/OpenAPI
- 随题样例：`public/samples/emerg-2025-09/`（r1 首批登记 + r2 迟到源修订），覆盖并发派车、多级转运、罕见组合、跨午夜任务

## 功能地图

| 模块 | 说明 |
| --- | --- |
| 来源批次 | 登记批次：实算每个文件 SHA-256 并与 batch.json 声明比对；登记字段含义与修订号；批次内容按修订不可变，运行中的任务继续引用启动快照，迟到修订另起运行 |
| 关系规则 | 事件/派遣/资源/到场/结案的引用与先后约束；车辆占用按实际任务区间 `[派遣, 到场+周转]` 以绝对毫秒核验，**跨午夜不算日期倒序**；审批后不可原地改，再编辑自动派生新版本 |
| 生成方案 | 记录要保留的全局事件类型、时长分布与随机种子；乐观锁保存——两管理员并发保存同一方案时展示冲突字段；审批门禁拒绝未审/宽松规则 |
| 生成运行 | 固定来源与规则快照，输出全新标识的多表演练包；两条路线可选（约束驱动条件采样 / 分布学习+批量抽样+约束筛选），均满足同一关系规则 |
| 质量核验 | 约定的总体统计比对、引用完整性、资源占用、时间可行性；直接标识扫描、源记录近乎复制、导出字段独特组合；两路线同一核验 |
| 发布清单 | 由输入计算产生，可回查来源批次（修订+文件哈希）、规则、运行参数（方法/种子/规模）与核验结果，支持重新校验与导出 |
| 学习效果校准 | 把合成包场景特征与匿名学员练习顺序、决策步骤、用时、标准处置依据及迁移测验关联；输出场景难度/区分度与训练安排对**未见场景正确率**的效应估计与区间；**不生成个人能力排名** |

## 测试账号

本工具为纯本地应用，**无后端账号体系、无需登录**。页面左下角的操作员选择（管理员A / 管理员B）仅作为本地身份标记，用于演示审批签名与「两人并发保存同一方案」的冲突处理。

## 操作与验证路径（建议顺序）

1. **来源批次** → 点「加载随题样例 r1」：查看文件哈希实算结果、字段含义表；点「源数据体检」可见 r1 中 2 条缺失到场、3 条结案时间异常（迟到修订素材）。
2. **关系规则** → 「新建标准规则」→ 检查约束后「审批」。
3. **生成方案** → 「新建方案」自动从批次学习分布 → 选择生成路线（界面有两路线适用条件说明）→ 保存 →「批准」。可尝试把容差改到系统边界外（如类型占比容差 50pp）再批准，会被门禁拒绝；引用未审批规则同样被拒绝。
4. **生成运行** → 对方案「开始生成」（WebWorker 进度条）→「查看输出」预览五张表、导出 CSV。
5. **质量核验** → 对运行执行核验：总体统计比对、引用完整性、资源占用（跨午夜安全）、时间可行性、直接标识、近乎复制、独特组合，附风险提示与核验范围声明。
6. **发布清单** → 生成清单后「回查视图」看 批次→规则→运行→核验 全链路哈希，「重新校验」逐项重算比对，可导出 JSON。
7. **迟到源修订演示** → 回到「来源批次」加载 r2：r1 标记「已被取代」；已完成的运行仍引用 r1 快照（运行记录中有提示），新运行默认使用 r2。
8. **并发冲突演示** → 两名操作员先后编辑同一方案：先保存者成功，后保存者看到冲突字段对照表（你的值 vs 库中当前值），可选择覆盖或放弃重载。
9. **学习效果校准** → 「学习效果校准」页点「一键生成四类验收样例并校准」（WebWorker 内运行）：查看方法选择依据、两条路径的效应区间、不同训练安排的未见场景正确率、场景难度/区分度、敏感性检查与证据限制。详见下方「学习效果校准」。

## 学习效果校准

培训复盘常看到「重复演练更快完成派车」，但分不清是学会了资源匹配，还是记住了某个场景的答案；不同演练包难度差异也会让简单前后平均分失真。本模块把**合成包中的场景特征**与**匿名学员的练习顺序、决策步骤、用时、标准处置依据、后续迁移测验**关联，估计场景难度、区分度，以及不同训练安排对**未见场景处置正确率**的影响。

两条估计路径估计同一个量（varied − repeat，百分点），按缺测与交叉覆盖程度、场景属性数量和教研方所需可解释粒度选择：

| 路径 | 口径 | 优点 | 局限 |
| --- | --- | --- | --- |
| 配对估计 | 随机交叉数据上，对同一学员「练习过的场景家族 + 未见迁移题」按家族分层的加权成对对比 | 直观、假设少 | 未完成成对练习时可用样本减少；一次只能吸收一个匹配层，难同时分离多个场景属性 |
| 层级反应模型 | `logit(正确) = α + θᵢ − b_f + β·varied + δ·transfer + γ·transfer·varied`，θ（学员基线）、b（场景难度）带岭先验 | 可利用不平衡与部分缺测，联合估计学员基线、场景难度与迁移表现 | 依赖模型结构，须做敏感性检查 |

**证据口径（强制）**：

- **重复尝试不是独立样本**：同一学员同场景多次作答先按学员聚合，自助法一律按学员聚类重抽。
- **答案泄漏不作泛化证据**：迁移题答案在测验前泄漏、或使用了该学员练习过的具体实例，均不计入未见场景估计（在诊断与敏感性中单列）。
- **退出 / 换版本保留可用性缺口**：学员退出、更换演练包版本造成的缺失记录不做插补，形成缺口并在诊断中显示；版本切换学员在两个版本分别计入。
- **规则更新后分开估计**：场景家族按演练包/规则版本分键（标准处置依据随规则版本变化），新旧训练效果**不跨版本合并**。
- **不生成个人能力排名**：学员编号为本地匿名标识（`T-xxx`），学员基线仅用于模型校正，不单独报告、不排序。

**验收样例（确定性，`seed` 决定，界面可生成）**：

- `comprehensive` 综合：同时覆盖重复场景、乱序训练、未见迁移题、日志缺失、包版本更新、答案泄漏。
- `paired-clean` 干净交叉：完整交叉、无缺失/泄漏，属性少 → 应推荐**配对估计**，效应区间不含 0。
- `missing-heavy` 缺失为主：配对可用学员大幅减少 → 推荐**层级模型**，配对覆盖率 < 50%。
- `leak-heavy` 泄漏为主：大量迁移题泄漏/复用练习实例 → 泛化证据受限，含泄漏变体与主估计不同。

**界面位置**：`学习效果校准`（`/#/calibration`）。点击样例查看：方法选择依据、两路径效应与 95% 区间、各安排未见场景预期正确率、场景难度/区分度（含可识别性）、敏感性检查、诊断（交叉覆盖/缺测/退出/版本切换/泄漏）与证据限制。报告以确定性的 `报告哈希` 落库于 IndexedDB。

**自动化验证**（`tests/calibration.test.ts`，实际执行）：

- 批改由「标准处置依据」重算（必需步骤齐全 + 无禁止步骤 + 未超时），规则更新后旧作答在新规则下不再自动成立；
- 答案泄漏题、练习过的实例、退出学员迁移记录被排除；重复尝试真实存在且按学员聚合；
- 方法选择：干净交叉+属性少 → 配对；缺失为主 → 层级；
- 配对效应方向正确且 95% 区间不含 0、学员聚类自助法同种子可复现；
- 层级与配对方向一致、给出 5 类敏感性变体；泄漏为主时含泄漏变体与主估计不同且主估计观测数更少；
- 场景难度与练习正确率反序一致、区分度样本不足时为 `null` 不伪造；
- 两版本各自估计不合并；报告不含个人排序字段。

## 复现说明

同一「方案 + 批次快照 + 规则版本 + 种子」必然产生同一演练包：发布清单记录了全部输入哈希（批次文件、规则、方案参数、输出表、核验报告），在「发布清单 → 重新校验」可逐项重算比对。

## 风险核验范围声明

基础风险核验只覆盖：①导出字段中的直接标识（模式匹配 + 源值逐字比对）；②与源记录的近乎复制；③已声明字段组合的独特性（k 阈值）。**不宣称能抵御针对特定目标的定制攻击**、背景知识链接或组合推断；演练包应按内部受控资料管理。

## 目录结构

```
src/domain/     纯领域逻辑（生成器A/B、约束、统计、隐私、核验、清单、冲突）
src/domain/calibration/  学习效果校准（类型、观测/诊断、两条估计路径与敏感性、验收样例）
src/services/   编排层（批次登记、运行/核验/校准 Worker 编排、清单、导出）
src/workers/    WebWorker 入口（生成 / 核验 / 校准）
src/pages/      八个页面（含学习效果校准）
src/db/         Dexie（IndexedDB）schema（v2 新增校准数据集/报告表）
public/samples/ 随题样例（r1 + r2 迟到修订，含 batch.json 声明哈希与 fields.json 字段字典）
scripts/gen-samples.mjs  样例再生成脚本（确定性，node scripts/gen-samples.mjs）
tests/          vitest 测试
```
